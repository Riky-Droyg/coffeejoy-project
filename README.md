# CoffeeJoy — Specialty Coffee Landing Page

CoffeeJoy is a responsive landing page for a specialty coffee brand. The project focuses on clear section navigation, adaptive layouts, and interactive elements for a modern marketing website.

## Live Demo

[View the live website](https://riky-droyg.github.io/coffeejoy-project/)

## Features

- Responsive layout for mobile, tablet, and desktop
- Section-based navigation for About, Benefits, Gallery, Testimonials, and Location
- Image gallery
- Testimonials slider
- Newsletter subscription form with validation and user feedback
- Contact and location section with directions and social links

## Getting Started

```bash
git clone https://github.com/Riky-Droyg/coffeejoy-project.git
cd coffeejoy-project
npm install
npm run dev
```

To create a production build:

```bash
npm run build
npm run preview
```
